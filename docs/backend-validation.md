## 本机编译限制

本机受限 Windows 环境中，标准 javac 的 JAR 路径解析抛出 AccessDeniedException，虽然文件内容可读取。改用 ECJ 3.36、Java 17 目标版本和展开的原始 Maven 依赖，成功编译业务及测试代码；随后使用 Maven resources:resources、resources:testResources、surefire:test 运行真实 Spring Boot 集成测试。临时编译器和依赖均位于仓库之外，没有修改项目的默认编译器设置。

因此，记录中的自动化测试确实执行通过，但不把本机标准 mvn test 全生命周期声称为通过。正常开发环境按指南运行 mvn test；MySQL 8.4 的部署环境仍建议在合并前复测。本轮没有使用真实 Claude 模型验证输出质量，也没有测试截图识别、正式团队页面或公网部署。

## 已修复的联调问题

MySQL 保存时间为微秒精度，首次响应原先带纳秒，导致相同报告两次响应的 created_at 不同。现改为保存后立即读回数据库结果；测试对首次和缓存响应做完整 JSON 相等断言。
