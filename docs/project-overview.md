# 项目概要

## 项目名称

AI投资教练（AI Investment Coach）

## 核心定义

用股票数据分析投资者的决策行为，找出不良投资习惯的AI教练平台。

它不是分析股票，而是分析人的投资决策行为。

## 用户类型

### 新手用户

1. 每日学习股市知识，获得积分
2. 用积分参与当日真实股票模拟实盘
3. AI基于经典理论提供量价、K线分析作为辅助信息
4. 交易结束后AI分析行为，生成个人投资性格画像
5. 用积分在商城兑换实物商品或优惠券

### 经验投资者

1. 上传券商交易记录CSV或K线截图
2. 系统自动还原对应日期的K线、量价、公告数据
3. AI分析行为，生成个人投资性格画像

### VIP用户

1. 实时行情和专业图表
2. 每日财经资讯AI摘要
3. 结合实时数据、资讯、技术指标和经典理论做综合行为辅助分析

## 第一阶段范围

第一阶段只完成MVP闭环：

```text
学习任务 -> 获得积分 -> 模拟交易 -> 保存交易记录 -> AI行为分析 -> 展示性格标签
```

暂不做：

- 真实证券账户交易
- 真实投资建议
- 复杂RAG知识库
- 完整商城履约
- TradingView级专业图表
