# 第一阶段MVP计划

## 阶段目标

在最短时间内做出一个能演示的基础软件，而不是把所有高级功能一次做完。

演示路径：

```text
打开App -> 完成学习 -> 获得积分 -> 进入模拟交易 -> 提交交易 -> AI生成行为分析 -> 展示性格标签
```

## Week 1：基础环境和仓库协作

- 杜君：创建GitHub仓库，推送项目骨架，维护README和接口文档
- Young：启动Spring Boot服务，完成健康检查
- Joo Jiho：启动FastAPI数据服务，完成健康检查
- 金佳亮：启动Expo App，完成首页基础UI

验收：

- 4个模块目录都能打开
- 至少3个服务有健康检查
- 所有人能从GitHub clone、创建分支、提交代码

## Week 2：核心接口跑通

- 杜君：完成AI行为分析mock接口
- Young：完成学习积分接口和交易记录接口
- Joo Jiho：完成CSV解析接口
- 金佳亮：完成模拟交易表单页面

验收：

- 前端能提交一笔模拟交易
- 后端能保存交易

- 数据服务能解析示例CSV

## Week 3：模块联调

- 前端调用后端
- 后端调用AI服务
- 数据服务输出的交易记录能转给AI服务
- App展示AI分析结果

验收：

- 完整MVP路径能走通
- README里有清晰运行方法
- 每个成员完成一次Pull Request
