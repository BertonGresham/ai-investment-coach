# 网页演示

零前端构建依赖的中韩双语网页演示。`index.html` 是产品首页，包含明确标记的合成行情、K 线、模拟买卖、持仓和成交记录；`review.html` 保留杜君的 AI 行为复盘子页面。

## 启动网页

在仓库根目录执行：

~~~powershell
python -m http.server 5173 --directory web-demo
~~~

浏览器打开 <http://localhost:5173> 进入行情与模拟交易首页，AI 复盘子页面为 <http://localhost:5173/review.html>。首页检查 `http://localhost:8080/api/health`；Young 的 `/api/trades` 尚不可用时，成交会进入浏览器 `localStorage`，并在状态栏和每条成交上标为“本机演示”。后端可用时按 `docs/api-contract.md` 提交并标为后端已保存。首页的行情与 K 线为本地合成示例，不是实时或历史行情。

从持仓或成交记录点击“AI 复盘”，首页会把该股票的成交明细带入复盘页。后端模式和本机演示模式会分别提示；复盘分析使用现有 AI 页面与 AI 服务接口，不重做模型调用或截图识别。若 AI 服务不可用，现有页面会明确显示本地规则模拟结果。

本机演示成交保存在浏览器中，关闭重开网页仍会保留；点击“清空本地演示记录”可清除。AI 分析结果当前仍由复盘子页面保存在内存中，未实现业务后端持久化分析结果。

全站右上角可切换简体中文/韩语。复盘子页面原有的交易表单、行为画像、截图队列与核对流程均保留。可一次选择最多 10 张 PNG/JPG/WebP 券商截图，单张不超过 8 MiB、合计不超过 32 MiB。重新选择会替换整个图片列表；无效选择不会清掉已有结果。选择时仅本机预览，点击“识别待处理图片”才会按顺序逐张发送给所配置的视觉模型。每张保留自己的状态与结果，失败不会丢弃其他结果；再次识别只处理待识别和失败项。停止或移除当前图片会中断队列，已完成的结果保留；停止浏览器请求不保证模型服务端停止处理或免除已发生费用。清空图片释放本机预览。

选择列表中的一张图片可单独核对、填表。同一持仓分批买卖时，勾选 2–10 张成交截图并点击“合并所选成交”。逐笔核对来源、时间、价格、股数及理由，确认同一账户、股票、市场和币种且无遗漏/重复后一次填入。支持多次买入、多次卖出、部分卖出与仍有持仓，也可选包含明确完整买卖的截图。合并不再次调用模型，不自动选择或配对其他截图。

已知股票/市场/币种冲突会阻止合并；身份缺失仍需本人核实。截图只有日期或未注明时区时保留原值，不要求补造时刻；理由可留空。明确成交总额与价格/股数可自动补算缺少项，单独标注来源。手续费、税费保留供核对但不计入当前盈亏。重复记录、卖出超过持仓会阻止确认。同日缺时刻时可用上下箭头调整列表并确认顺序，不凭日期推断盘中先后。暂不支持做空、期初持仓、跨账户/币种汇总、拆股或多持仓自动匹配。

确认后可继续逐笔修改，原表单的时间、均价和累计数量为只读汇总。分析结果保留“第 1 次买入、第 1 次卖出、第 2 次买入……”的完整时间线及各次理由。买入/卖出均价按数量加权，已实现盈亏由后端按成交顺序、移动加权平均成本计算，只计算卖出部分；剩余持仓单独列出，不计算未实现盈亏，不含手续费、税费和汇率。日 K 背景仍仅对应首次买入，不代表所有加仓或卖出时刻。整组持仓计为一个行为样本。

点击“分批演示案例”可直接载入虚构明细，不调用截图识别。也可运行 `scripts/make-execution-fixtures.ps1` 生成四张明确标记为虚构的测试图片（保存在系统临时目录）。买入 100×10、卖出 120×5、买入 80×10、卖出 110×10：买入均价 90、卖出均价约 113.3333、剩余 5 股、已实现盈亏约 333.3333。不要用 `(卖出均价 - 买入均价) × 累计买入数量` 计算这种交错成交。

未完成识别、待核对、识别失败或资金流水记录不能直接触发分析，避免误用原来的示例。取消核对可继续手动分析，再次选中该条可重新核对。缺失时间及时区的字段留空，需手动补齐。自评分只是模型估值，不是识别准确率。切换语言会停止进行中的请求并保留已完成结果，合并确认需重新勾选；模型原始提示保留请求时语言，界面标签随语言切换。修改 API 地址会清除旧识别结果，重新核对。修改合并选择、移除/替换图片或编辑表单会撤销待确认合并。Mock 后端会明确提示未执行真实视觉识别。本演示与 AI 服务都不把上传图片写入磁盘。

截图识别会先区分证券成交与资金流水。利息、分红、入出金等记录只显示分类提示，不填入交易、不生成行为标签。类型/方向不明同样不导入。单图填表时另一侧保持空白；多图需显式勾选并核对，不会自动一次分析全部图片或批量记账。一张图包含多笔独立成交尚不支持自动拆分，需逐笔裁剪后上传。

## 自动行情与书籍参考

勾选“自动获取买入前日 K”后，点击分析会先读取历史背景，无需手写 K 线摘要。只支持美股，按本机时区输入交易时间，转换为纽约日期后排除买入当天的日 K。展示行情区间、计算指标、Selden (1912) 书籍笔记和来源链接。

初始案例及“载入演示案例”使用明确标记的合成行情。选择“真实历史行情 · Yahoo”才读取真实数据，行情获取不需要 LLM 密钥。股票、日期、来源、语言或理由类型变化会清除旧背景；晚返回的请求不会覆盖新表单。

自动背景需要后端运行。读取失败时会停止提交并提示错误，不以虚构行情替代；可重试或取消自动获取，仅按填写的理由复盘。关闭自动获取时，摘要为可选的用户补充，并标记未经验证。

书籍笔记目前按主题规则匹配，非 AI 生成。行为结果顶部另行标明 Mock 或 LLM。真实 Embeddings 建库需要单独配置；LLM/OCR 的离线回归不代表真实账户连通性或识别准确率，演示前应使用所选平台另行验证。

前端状态回归测试：`node --test web-demo/tests/*.test.cjs`（仓库根目录，无需安装 npm 包）。

## 连接 AI 服务

API 密钥只放在 `ai-service/.env`。在仓库根目录的 PowerShell 里运行 `if (-not (Test-Path .\ai-service\.env)) { Copy-Item .\ai-service\.env.example .\ai-service\.env }`，再用记事本打开：`notepad .\ai-service\.env`。使用 Claude 时设置 `LLM_PROVIDER=anthropic`、`ANTHROPIC_API_KEY=你的Claude密钥`、`ANTHROPIC_MODEL=claude-sonnet-4-6` 和 `USE_MOCK_LLM=false`，保存后重启 AI 服务。示例模板 `.env.example` 只能保留空白占位符，不能把真实密钥写进去；`.env` 已由 Git 忽略。OpenAI 接入也保留，须配置 `LLM_PROVIDER=openai` 与独立的 `OPENAI_API_KEY`。

在 `ai-service` 目录配置 `.env` 并启动 FastAPI：

~~~powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001 --env-file .env
~~~

首次启动默认是 `USE_MOCK_LLM=true`，网页状态显示为后端 Mock。配置所选平台的有效密钥并设置 `USE_MOCK_LLM=false` 后，才会调用真实 LLM 和视觉模型。Claude 可以直接分析自动行情页附带的书籍笔记；可选的 Chroma 向量建库另需 OpenAI Embeddings 密钥。网页源站 `localhost:5173` 已列入 AI 服务的开发 CORS 白名单；真机或局域网演示时，在 `AI_SERVICE_CORS_ORIGINS` 中加入网页实际使用的来源地址。

网页端不需要 `npm install`。真实模型和 RAG 仍需要安装 Python 服务依赖及配置相应 API Key。
